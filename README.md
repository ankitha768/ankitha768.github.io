## Run Locally

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/ankitha768/ankitha768.github.io.git
cd ankitha768.github.io
```

No installation or build step is needed.

## Deploy with GitHub Pages

This repository is named `ankitha768.github.io`, so GitHub Pages can serve the site directly from the `main` branch.

In GitHub:

**Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)**

After deployment, the site will be available at:

https://ankitha768.github.io/

## Customization

- Update profile links in `index.html`.
- Update project descriptions or add GitHub project links when the corresponding repositories are public.
- Replace the email address if needed.
- Modify colors, typography and responsive behavior in `style.css`.
